# to-do-list

## Open the app

Open `index.html` in a modern web browser. The app is self-contained, so it does not need an installation, server, or internet connection.

## Manage tasks

- Enter a task in the text field and select **Add task** or press Enter.
- Select the checkbox next to a task to mark it complete. Select it again to reopen the task.
- Select the **×** button beside a task to delete it.
- The active-task counter shows how many tasks are not yet complete.

## Saved progress

Tasks and their completion status are saved automatically in the browser's local storage. They remain available when you reopen the app in the same browser, provided browser storage has not been cleared.

Saved tasks are local to this browser and device; they are not synced to other devices or backed up. If browser storage is unavailable or saving fails, the app displays a notice. Changes in that case may be lost when you leave or reload the page.
